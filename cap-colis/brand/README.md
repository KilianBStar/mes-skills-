# Kiliroute : logo et règles d'usage

## L'idée
La pastille d'arrêt de la carte, cochée : le colis est livré. Le livreur voit cette forme toute la journée dans l'app, le logo la reprend.

## Fichiers
| Fichier | Usage |
|---|---|
| `logo/logo-horizontal.svg` | Logo principal (fond clair) |
| `logo/logo-horizontal-blanc.svg` | Sur fond sombre ou photo |
| `logo/logo-horizontal-noir.svg` | Impression une couleur |
| `logo/logo-empile.svg` | Espaces carrés |
| `logo/symbole-bleu.svg`, `-noir`, `-blanc` | Symbole seul |
| `logo/symbole-petite-taille.svg` | En dessous de 24 px (coche plus épaisse) |
| `logo/mot-cap-colis.svg` | Nom seul |
| `icons/app-icon.svg` + PNG 1024/512/192/180 | Icône d'app (fond bleu, iOS arrondit les coins) |
| `icons/app-icon-nuit-1024.png` | Variante sombre |
| `icons/favicon.svg` + PNG 48/32/16 | Onglet du navigateur |
| `planche-presentation.png` | Vue d'ensemble |

## Couleurs
| Nom | HEX | RVB | CMJN (approx.) |
|---|---|---|---|
| Bleu Cap | #1E62D6 | 30 98 214 | 86 54 0 16 |
| Encre | #161A22 | 22 26 34 | 35 24 0 87 |
| Bleu nuit (écran sombre) | #5B8DEF | 91 141 239 | 62 41 0 6 |

Pour l'impression, faites vérifier les valeurs CMJN par l'imprimeur (aucune référence Pantone choisie).

## Typographie
Google Sans Medium (licence SIL OFL 1.1). Le nom du logo est converti en contours : pas besoin de la police pour l'afficher.

## Règles
- Espace libre autour du logo : la hauteur de la coche.
- Taille minimale : symbole 16 px (version petite taille), logo horizontal 96 px de large.
- Fonds autorisés : blanc, gris clair, encre, bleu Cap (symbole blanc).
- À éviter : déformer, changer les couleurs de la coche, ajouter une ombre ou un dégradé, poser le logo bleu sur une photo chargée.

## Limites
Aucune recherche d'antériorité de marque n'a été faite. Avant un dépôt de marque, faites vérifier le nom et le logo par un professionnel.
